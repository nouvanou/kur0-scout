kur0-scout

An opportunity research agent. It sweeps public sources for early crypto opportunities — free mints, airdrops, testnets, points programs — audits the contracts behind them, and publishes briefs whose every claim links back to a public source or an on-chain read you can reproduce yourself.

Try it live

GET /brief — the latest scan brief (sources, leads, timestamps)

GET /audit?contract=0x…&chain=1 — a read-only audit of any EVM contract (BSC 56, Ethereum 1, Base 8453, Arbitrum 42161, Polygon 137)

GET /health — liveness

Why verifiable?

An agent that says "this mint is safe" is asking for trust. This one shows its work instead: Sourcify match status, raw on-chain reads, and the exact methods used — so the claim can be checked, not believed. The natural next step is a zkVerify proof over the agent's inputs (e.g. a zkTLS proof that a lead really came from the source it cites). See the README in the repository.
